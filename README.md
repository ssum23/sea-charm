# sea-charm

물고기를 잡은 자리에서 **가져가도 되는지** 알려주고, **길이를 재는** 앱.

금어기와 금지체장은 어기면 수산자원관리법 제65조제2호에 따라
**1천만원 이하의 벌금** 대상이다(과태료가 아니다). 비어업인에게도 그대로 적용된다.
바다에서는 인터넷이 끊기니, 이 앱은 **인터넷 없이 판정한다.**

주소 — https://ssum23.github.io/sea-charm/

---

## 네 화면

| 주소 | 화면 | 하는 일 |
|---|---|---|
| `/` | 귀항 도장 | 출항·귀항을 찍는다 |
| `/charm` | 오늘의 바다 부적 | 물때와 띠로 한 장. 물때가 바뀌면 새 장 |
| `/catch` | 이거 가져가도 되나요 | 어종 → 길이 → 가져감 / 놓아줌 / 확실치 않음 |
| `/log` | 조과 기록 | 방생률·어종별·최고 기록 |

## 만든 방식

| | |
|---|---|
| 화면 | Next.js — 정적 파일로만 내보낸다(`output: 'export'`). 서버가 없다 |
| 판정 | `app/judge.js` — **순수 함수.** 화면·네트워크를 쓰지 않는다 |
| 기준표 | `app/species.json` — 82종. 법령 원문과 대조한 것 |
| 부적 | `app/부적.js` — 물때를 **달의 위상으로 직접 계산**한다. 외부 자료를 받지 않는다 |
| 저장 | 기기 안(`localStorage`)에만. 서버로 아무것도 보내지 않는다 |
| 외부 통신 | **0건.** 글꼴까지 앱 안에 넣었다 |

**판정 엔진을 화면과 분리한 이유** — 틀리면 쓰는 사람이 벌금을 문다.
가장 위험한 코드를 가장 단순하게 두고, 화면 없이 값만 넣어 검산한다.

`web/` 은 엔진을 **복사하지 않고** `../app/` 의 원본을 직접 읽는다.
복사본을 두면 어느 날 한쪽만 고쳐지고, 그 순간 판정이 틀린다.

## 판정 순서 — 바꾸지 않는다

```
1) 기준표에 없는 어종               → 확실치 않아요  (별칭까지 찾아본 뒤)
2) 후보 지역 전부가 금어기           → 놓아주세요    (길이를 보지 않는다)
3) 지역에 따라 금어기가 갈린다        → 확실치 않아요  (어디서 잡으셨나요)
3-b) 지역에 따라 금지체장이 갈린다     → 확실치 않아요  (어디서 잡으셨나요)
4) 체장 규정 자체가 없는 어종         → 가져가도 돼요  (길이를 묻지 않는다)
5) 길이가 없다                     → 확실치 않아요  (길이를 묻는다)
5-b) 상식 밖의 값 (cm>200 / g>50000) → 확실치 않아요
6) 길이 ≤ 금지체장                 → 놓아주세요    (예외 없다)
7) 길이 − 금지체장 ≤ 1cm            → 확실치 않아요  (넘은 쪽만)
8) 그 외                          → 가져가도 돼요
```

**6번이 7번보다 먼저다.** 순서를 바꾸면 놓아줘야 할 물고기가 빠져나간다.

판정을 바꾸지 않고 주의만 얹는 것 — 복어 독 경고 · 「국가 기준에 규정 없음」 안내 ·
관행 방생 안내(칭찬만 끈다) · 좌표 예외 안내.

**금지체장은 모두 「이하」 기준이다.** 법 표기가 「N센티미터 이하」이므로
기준과 **정확히 같은 값도 금지**다.

**지역 기준은 국가 기준보다 느슨해질 수 없다** — 법 제14조제4항이 「강화하여」로 정한다.
그래서 위치는 필수가 아니라 **조건부**다. 전국 기준으로 「놓아주세요」가 나오면
어느 지역이든 놓아줘야 하므로 위치를 묻지 않는다.

## 켜는 법

```
cd web
npm install
npm run dev        # http://localhost:3000
```

## 검산

```
cd web && npm test        # 판정 85 + 부적 83 = 168건
```

**168건이 다 통과해야 배포된다.** 하나라도 실패하면 배포가 멈춘다
(`.github/workflows/배포.yml`).

부적 검산은 문구를 전부 훑어 **금지어를 직접 검사**한다 —
어획을 예언하는 말, 안전을 예언하는 말, 나쁜 운세는 하나도 나오지 않는다.
안전을 예언하면 그 말을 믿고 바다에 나간 사람이 위험해진다.
